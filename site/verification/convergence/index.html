Convergence Test

The Convergence module evaluates data volume convergence. It determines whether your model's performance has stabilized or if it would significantly benefit from more training data.

By training the model on progressively larger subsets of your data, VV4ML analyses the stability of the resulting evaluation metrics.

How It Works Mathematically

Given a list of dataset sizes \([N_1, N_2, \dots, N_k]\) configured via YAML, VV4ML: 1. Subsamples the training dataset to match each specified \(n\). 2. Trains the chosen model architecture on each subset. 3. Computes the target metric (e.g., RMSE or StandardDeviation) for each step. 4. Checks if the metric stabilizes. If the metric fluctuation (measured via StandardDeviation) across the largest data sizes is below your threshold, the test passes:

\[ \sigma(\text{metrics}_{k-2}, \text{metrics}_{k-1}, \text{metrics}_k) \le \text{threshold} \]

YAML Configuration

To activate and configure this test, define the convergence blocks under both gate_thresholds and test_configurations:

```yaml gate_thresholds: verification: convergence: - field: "loss" metric: "StandardDeviation" # Checks the stability of the metric value: 0.01 # Maximum allowed standard deviation

test_configurations: verification: convergence: n_rows: [500, 1000, 2500] # Subsets of data to evaluate
